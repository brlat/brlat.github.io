# .bes点字データをカタカナに変換

## 何をするものか

これは、.bes形式の点字データを読み込み、カタカナに変換して表示するものです。

[このページ brlat.github.io](https://brlat.github.io)
から利用できます。

スマホやタブレット端末で、サピエ図書館などの点字データ、.bes形式、をダウンロードして、それをブラウザで開いて、カタカナに変換して、内容を音声読み上げで確認できるようにします。

サピエ図書館からダウンロードした点字データは.zip圧縮されていますが、このウェブアプリで読み込めるのは.besファイルです。

iPhoneやiPadなどでダウンロードした.zipファイルは、「ファイル」アプリで.zipファイルを展開して、.besファイルに事前にしておく必要があります。

## iPhoneやiPadで.bes点字データを仮名に変換して読む他のアプリ

iPhoneやiPadで、.bes点字データを仮名に変換して読むことができるアプリには、下記のものなどがあります:

- [「BrailleTalk」](https://apps.apple.com/jp/app/brailletalk/id1067503021)

[ニュー・ブレイル・システム社](http://www.nbs.co.jp/) のiPhone用の優良アプリです。

Chromeブラウザで、サピエ図書館の点字データをダウンロードして、「ファイル」アプリに保存された.zipファイルを「共有」から「BrailleTalk」で開くことで、カタカナに変換された図書を音声で読むことができます。

しおり機能や、読み上げの設定変更などがあり、とても便利です。

- [ユニバーサルデザイン対応の電子書籍閲覧アプリ「UDブラウザ」](https://psylab.hc.keio.ac.jp/app/UDB/)

視覚障害などの学生が読みやすい教科書データを読むためのアプリですが、2026年9月のバージョンアップで、国会図書館の障害者サービス「みなサーチ」の検索・ダウンロードに対応しています。

pdfやデイジー図書に加えて、.bes点字データにも対応しているということです。

「みなサーチ」からダウンロードしたものでなくても、「ファイル」アプリにある点字データの.zipファイルも、「共有」から「UDブラウザ」で開くことができます。

ただ、2026年9月現在、私の使用環境では、変換された図書を、ページ送りしてうまく読むことができません。

環境の問題なのかもしれません。
